Telegram setup

  1. 1. Create a bot with @BotFather and copy the token.
  2. 2. Put TELEGRAM_BOT_TOKEN in .env.
  3. 3. Start the app, send /id to the bot.
  4. 4. Add the chat ID above or in TELEGRAM_CHAT_ID.
  5. 5. Send /status to confirm.
Commands: /status /positions /signals /pause /resume /kill /risk 0.5 /report /mode
